# 酒吧问题出席人数预测的 MF / MB 学习模型：计算建模方案

> 数据：`allpredict.csv`（100 名被试 × 435 试次的出席人数预测，第 1 行为真实出席人数）
> 分析范围：**最后 400 个试次（第 36–435 试次）**；酒吧容量 **C = 60**
> 代码：`代码/`（Python 3，numpy / scipy / pandas / matplotlib），运行方法见 `README.md`
> 本文件只写方案，不含数据结果。结果见 `结果报告.md`。

---

## 一、理论层

### 1. 研究问题

在 100 人重复进行的酒吧博弈（El Farol bar problem）中，每个试次被试先预测本次会有多少人去酒吧，再决定去或不去。人数 ≤ 60 时去的人获益，> 60 时去的人吃亏。试次结束后公布真实出席人数 A_t。

研究问题：**人们根据什么形成对下一次出席人数的预期？**

- **无模型（model-free, MF）**：把过去的出席人数缓存成一个"经验平均值"，用预测误差逐次修正，不考虑博弈结构。
- **基于模型（model-based, MB）**：利用对博弈结构的内部模型来预测。被试知道容量是 60，并且学习"拥挤之后接下来会怎样、不拥挤之后接下来会怎样"这一状态转移规律，再从当前状态出发向前推断。
- 人群中两种方式的比例如何？每个人是混合使用两种方式，还是各自偏向其中一种？

### 2. 理论假设

| 编号 | 假设 | 可检验的预测（模型无关的行为特征） |
|---|---|---|
| H1 学习 | 预测会随历史出席人数更新 | 学习模型（MF / MB / 混合）优于无学习基线 |
| H2 MF | 预测是对出席人数的指数加权平均（delta 规则） | 上一试次人多，本次预测**也高**：对 (A_{t−1} − 60) 的斜率 > 0 |
| H3 MB | 预测基于"容量定义的状态 + 状态转移"模型 | 上一试次拥挤，本次预测**更低**（预期他人会退出）：斜率 < 0 |
| H4 个体差异 | MF 与 MB 的使用存在个体差异 | 不同被试的最优模型不同；混合模型的 MB 权重 w 在个体间分散 |

MB 策略在本环境中是"有利可图"的：一个人去不去会影响别人下次去不去，所以出席人数在拥挤与不拥挤之间来回摆动，呈负自相关。MF 的缓存平均看不到这种结构。

## 二、模型形式化

### 1. 计算框架：决策，还是知觉判断 / 预测（无奖赏）？

- 本分析的数据是**预测**（报告一个 0–100 的数），不是"去 / 不去"的选择。预测本身**没有外部奖赏**；反馈是真实出席人数（完全信息）。
- 因此计算框架是**判断 / 预测**，对应强化学习中的**预测问题**（policy evaluation，学习对某个量的期望），而不是控制问题（选择行动以最大化奖赏）。
- 学习信号是**状态预测误差** δ_t = A_t − 预期值，而不是奖赏预测误差。delta 规则 / Rescorla–Wagner / TD(0) 在这里用来学习"出席人数的期望"。
- （扩展）"去 / 不去"的选择属于有奖赏的**决策**框架：去且 A_t ≤ 60 得 +1，去且 A_t > 60 得 −1，不去得 0。本方案不建模选择数据。

### 2. 模型类别

预测误差驱动的联结学习（delta 规则），放在 MF / MB 双系统框架下（Daw et al., 2005, 2011），共 4 个模型：

| 模型 | 类别 | 用于检验 |
|---|---|---|
| M0 无学习基线 | 固定预期 + 个体偏差 | H1 的对照 |
| M1 MF | 无模型 delta 规则：只缓存一个值 | H2 |
| M2 MB | 基于模型：用容量定义状态，学习状态转移预期 | H3 |
| M3 混合 | MF 与 MB 加权，w 为 MB 权重 | H4 |

### 3. 具体算法

符号：A_t 为第 t 试次真实出席人数（全组共用，对单个被试是外生的）；y_t 为被试在看到 A_t **之前**报告的预测；C = 60。

**M1 MF（Rescorla–Wagner / delta 规则）**

```
预期：  μ_t = V_t + b
更新：  δ_t = A_t − V_t
        V_{t+1} = V_t + α · δ_t
```

- α → 0：预期固定不变。
- α = 1：直接拿上一次的出席人数当预测。

**M2 MB（以容量定义状态的一步转移模型）**

```
状态：  s_{t−1} = 1[A_{t−1} > C]          （上一试次是否拥挤：用到博弈规则 C = 60）
预期：  μ_t = M_t(s_{t−1}) + b            （从当前状态出发，按转移模型向前预测）
更新：  δ_t = A_t − M_t(s_{t−1})
        M_{t+1}(s_{t−1}) = M_t(s_{t−1}) + α · δ_t   （只更新实际经历的转移）
```

- M(s) 是被试学到的转移预期 E[A_t | s_{t−1} = s]。
- 如果被试学会了"拥挤之后人会变少"，就有 M(拥挤) < M(不拥挤)，于是预测出现反转。

**M3 混合（Daw 式加权）**

```
μ_t = w · M_t(s_{t−1}) + (1 − w) · V_t + b    （V 与 M 用同一个 α 并行学习）
```

**M0 无学习基线**

```
μ_t = C + b
```

**作答模型（4 个模型相同）**

预测是 0–100 的整数，采用离散正态，并混合固定的失误率：

```
p(y_t) = (1 − ε) · [Φ((y_t + 0.5 − μ_t)/σ) − Φ((y_t − 0.5 − μ_t)/σ)] + ε / 101
```

ε = 0.01 固定，用来吸收误触等离群作答（例如报告 0 或 100）。

**初始化**：所有潜变量 V 和 M(·) 在窗口起点（第 36 试次）设为容量 60，代表"无偏先验"。MB 在第 36 试次所需的"上一试次状态"取第 35 试次的真实出席人数。

### 4. 参数（范围）

| 参数 | 含义 | 范围 | 出现于 |
|---|---|---|---|
| α | 学习率 | [0, 1] | M1, M2, M3 |
| w | MB 权重（0 = 纯 MF，1 = 纯 MB） | [0, 1] | M3 |
| b | 个体预测偏差（系统性高估或低估） | [−20, 20] | 全部 |
| σ | 作答噪声标准差 | [0.5, 30] | 全部 |
| C | 容量 | 固定 60 | M2, M3（定义状态）、M0 |
| ε | 失误率 | 固定 0.01 | 全部 |

参数个数：M0 = 2，M1 = 3，M2 = 3，M3 = 4。

## 三、统计实现层

### 1. 参数估计

- **方法**：逐被试最大似然估计（MLE），使用 L-BFGS-B 有界优化。
- **起点**：多起点防止局部极小。
  1. 网格起点：α 取 201 个网格点。在高斯近似下，b、w 有最小二乘闭式解，σ 取残差标准差。取似然最好的 3 个网格点作为起点。
  2. 另加 3 个随机起点。
  3. 所有起点中取最优。
- **加速**：潜变量轨迹只依赖 α 和全组共用的 A 序列，与被试作答无关，所以网格轨迹只算一次，可以复用。
- **剔除规则**（事先确定）：RT 缺失（超时未作答）的试次不计入似然，但模型仍用该试次的 A_t 更新。

### 2. 模型比较

1. **固定效应**：总 AIC、总 BIC；逐被试最优模型计数。
2. **随机效应贝叶斯模型选择（RFX-BMS）**（Stephan et al., 2009）：
   - 用 −BIC/2 近似对数模型证据。
   - 估计各模型在人群中的期望频率、超越概率 XP。
   - 用贝叶斯遗漏风险 BOR 计算受保护超越概率 PXP（Rigoux et al., 2014）。
   - 另做只比较 MF vs MB 的二模型 BMS。
3. **时间前向交叉验证**：用窗口前 200 个试次估参，在后 200 个试次上计算样本外对数似然。
4. **后验预测检验**：用每个人的拟合参数模拟 50 次，检验模型能否复现模型无关的行为特征：对 (A_{t−1} − 60) 的斜率，以及"拥挤后 − 不拥挤后"的平均预测差。

### 3. 参数恢复

- **三种参数取值方案**：
  - 经验参数（全部被试）：每个模型用 100 名真实被试的拟合参数。其中包含大量 α≈0 的退化参数，此时 MF / MB / 混合在行为上与基线等价。
  - 均匀抽样：α ~ U(0,1)，w ~ U(0,1)，b ~ U(−3,3)，σ ~ U(2,8)，检验设计层面的可辨识性。
  - 经验参数（对应类型被试）：每个模型只用"该模型为 BIC 最优"的被试的参数，有放回抽到 100 名。混合模型改用 0.1 ≤ w ≤ 0.9 且 α > 0.001 的被试。这一方案回答：真实的 MF 型、MB 型被试能否被正确认出来。
- **流程**：每种方案、每个模型模拟 100 名合成被试。合成被试使用与真实实验相同的 A 序列和有效试次掩码，然后用同一模型重新拟合。
- **指标**：真值与估计值的 Pearson / Spearman r、偏差、RMSE；"真值 i × 估计值 j"的交叉相关，用来检查参数之间的权衡。
- **判据**（经验标准）：r ≥ 0.8 为好，0.5–0.8 为中等，< 0.5 为差。

### 4. 模型恢复

- **流程**：沿用参数恢复的合成数据（三种方案 × 4 个生成模型 × 100 名）。每份数据用全部 4 个模型拟合，按 BIC（另报 AIC）判定最优模型。
- **输出**：
  - 混淆矩阵 p(判定为 k | 由 m 生成)。
  - 反演矩阵 p(由 m 生成 | 判定为 k)。
  - MF vs MB 二选一的区分率。
- **判据**：对角线 ≥ 0.7，说明模型可区分。
