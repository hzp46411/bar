# MF_MB预测学习：酒吧问题出席人数预测的 MF / MB 强化学习建模

用 `allpredict.csv`（100 名被试 × 435 试次的出席人数预测）的**最后 400 个试次**（第 36–435 试次），在**容量 C = 60** 的设定下，比较 4 个模型：

- M0 无学习基线
- M1 无模型（MF）delta 规则
- M2 基于模型（MB）：以容量定义状态，学习状态转移预期
- M3 混合 MF + MB

完整方案见 [`计算建模方案.md`](计算建模方案.md)。

## 目录

| 路径 | 内容 |
|---|---|
| `代码/common.py` | 数据读取、4 个模型的学习规则、似然、拟合（MLE 多起点）、模拟、行为特征 |
| `代码/01_describe.py` | 环境结构与模型无关的行为特征（含置换零分布） |
| `代码/02_fit.py` | 逐被试参数估计 → `结果/拟合结果.csv` |
| `代码/03_compare.py` | AIC / BIC、RFX-BMS（XP、PXP）、时间前向交叉验证、后验预测检验 |
| `代码/04_recovery_sim.py` | 参数恢复 / 模型恢复的模拟与再拟合（分块检查点，可断点续跑） |
| `代码/05_recovery_analysis.py` | 参数恢复指标、模型恢复混淆矩阵 |
| `代码/06_figures.py` | 全部图 → `图/` |
| `代码/run_all.sh` | 一键按顺序运行（已完成的步骤自动跳过） |
| `数据/` | 放 `allpredict.csv`、`allpredict_rt.csv`（仓库为公开仓库，原始数据不随仓库发布） |
| `结果/`、`图/`、`结果报告.md` | 运行后生成（未经确认不推送到公开仓库） |

## 复现

```bash
pip install numpy scipy pandas matplotlib
# 把 allpredict.csv 与 allpredict_rt.csv 放到 MF_MB预测学习/数据/
bash MF_MB预测学习/代码/run_all.sh
```

- 4 核机器上全部运行约 45 分钟，其中恢复检验约 40 分钟。
- 所有随机数都有固定种子，结果可完全复现。
- 中断后重新运行 `run_all.sh`，会从检查点继续。

## 关键设定

| 项目 | 设定 |
|---|---|
| 分析窗口 | 第 36–435 试次；潜变量在第 36 试次初始化为 60 |
| 剔除 | RT 缺失（超时）的试次不计入似然 |
| 作答模型 | 离散正态 + 固定失误率 ε = 0.01 |
| 参数范围 | α ∈ [0,1]，w ∈ [0,1]，b ∈ [−20,20]，σ ∈ [0.5,30] |
